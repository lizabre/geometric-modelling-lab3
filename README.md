# Лаб. №3 — Криві Безьє 3-го порядку (варіант 28, ведмедик)

    npm install
    npm run dev      # http://localhost:5173

- `src/bezier.js` — формула кубічної кривої Безьє та цикл побудови контуру
- `src/bear.js` — опорні точки малюнка (шляхи з кривих Безьє), порядок шарів
- `src/scene.js` — Three.js: заливка, контури, характеристичний багатокутник
- `src/ui.js` — приховування багатокутника, перетягування точок, експорт у JSON
- `src/morph.js` — анімація: ведмедик → зірки (інтерполяція опорних точок, розбиття сегментів де Кастельжо)
- Ваги керуючих точок (раціональні криві Безьє): формула в `src/bezier.js`, керування в `src/ui.js`
